السلامة الاحتياطات

  • A work permit must be issued, the maintenance staff should be qualified and carry the suitable safety category.

  • Safety fence (rope) with caution marks surrounding the work area is required.

  • Wear safety helmet, shoes.

  • Close manual valve for indicator line

Tools and Equipments

  • Oven temperature tester (druck DBC 150/650 series)

  • Screw driver

  • Set of key

العمل الذي يتعين القيام به

Steps to prepare for test

  1. Review technical reference material and manufactures manual.

  2. Obtain copy of indicator setting values record it in its MPRDS.

  3. Remove temperature indicator and take it to lab

  4. خذ قراءة 0% و25% و50% و75% و100% وسجلها في ورقة البيانات

Calibrating procedure

  1. Put the temperature indicator into the oven and record the value MRDS check if the reading is correct

  2. If there is any error, adjust the temperature indicator and repeat step 1 until reach the correct reading

Return indicator to Service

  1. Remove temperature indicator from oven

  2. Return the temperature back to its location

  3. Open manual valve for temperature indicator line

  4. Pace a copy of test result in the field maintenance file
