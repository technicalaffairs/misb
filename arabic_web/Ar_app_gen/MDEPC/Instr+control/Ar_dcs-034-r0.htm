 LE 108 - Logic Input Module

الستوم - فرنسا

رقم الوثيقة:     DCS-034-r0

صدرت إلى:      Nubaria PS

حالة:        موافقة

إجراء:
Equipment Inspection (I1-W1)

موافقة تاريخ :      08 March 2009

تاريخ المراد مراجعتها:     مارس 2014

 

مقدمة

This document outlines the equipment inspection I1, which must be performed on weekly bases as indicated by W1 in the title block.

LE108 عبارة عن وحدة اكتساب منطقية تحتوي على 16 مدخلاً منطقيًا مقدمة من جهد العملية، مع نقطة داخلية مشتركة متصلة بالقطب +.

Dimension:

Height: 233 mm عرض:  1 slot = 25.4 mm
Depth: 220 mm Weight: 0.380 kg

عملية

A process interface consists of :

  • A circuit for distribution and monitoring of the process voltage

  • 16 testable logic inputs based on opto-isolators

An interface with the 2000 I/O backplane bus consists of :

  • A circuit for plugging in with power on

  • An 2000 I/O bus slave interface 

  • Input-output registers.

Controls and Indications on The Front Panel

ضوء LED أخضر في الأمام تشير اللوحة إلى ما إذا كانت الوحدة تعمل أم لا.

It remains on if the module is operating correctly and goes out in case of faulty operation (fault detected in the hardware or configuration, use of the module).

Input Elements

The module has 16 logic input elements for acquisition of 16 free contacts. Each element is based on an opto-isolator which provides galvanic isolation between the process and the internal voltages.

The module monitors the possibility of the inputs to be switched to 1 or 0. 

Process Voltage

The process voltage is supplied by the backplane connector (distributed voltage), or by the process connector (external voltage).

A logic input based on an opto-isolator indicates the presence of the process voltage.

حماية

General protection on the process voltage +Vp by CTP with maximum tripping current at 20C: 0.75 A

المسودة الأولى بدأها المهندس. محمد توفيق اختبار م. بهاء عبد الوهاب، تمت مراجعته من قبل شركة MDEPC لضبط الجودة. عادل النجار، مقبول المدير العام م. محمد الشريف، معتمد من م. رأس أحمد صوان قطاع محطة كهرباء النوبارية.

السلامة الاحتياطات

  • A work permit must be issued

  • يجب استخدام معدات الحماية الشخصية (أحذية السلامة، الخوذة، التنفس قناع، نظارات السلامة)

  • Maintenance staff should be well trained and qualified.

  • Caution marks must be hanged on the work place, safety fence around the work place.

أدوات والمعدات

  • Complete tool set.

  • الاستهلاك: ≥ 50 مللي أمبير

- عملية :

  • LE 108 A-1 module

  • Voltage 48 V (38.4 V to 57.6 V)

  • Consumption  ≤ 175 مللي أمبير

  • Read current 10.5 to 14.5 mA

  1. Check the interface leds

There is a led in the front of the card, if it green the card is OK
