    العمل المراد تنفيذه

    Steps to Prepare for test

    1. Review technical reference material and manufactures manual.

  •  الحصول على نسخة من ملف الصيانة الميدانية لنظام الهاتف الآلي.

    • Testing Procedure

    1. التحقق من جهد الخرج لمصدر الطاقة ( 24 فولت )

    2. افصل وحدة إمداد الطاقة (A711) عن طريق إيقاف التشغيل (F1) ومضخم الطاقة (SE425) عن طريق إيقاف التشغيل (F2)

    3. Clean and inspection all cards

    • Input device ( A206 )

    • Monitoring module ( A425 )

    • Double- pre amplifier. Balanced ( A111 )

    • Gong and alarm tone gen. ( A381 )

    • Connection block ( SAK4 )

    1. قم بتوصيل مصدر الطاقة وتحقق من جهد الخرج ( 24 فولت ) ومصابيح LED على جميع    البطاقات

    2. Make a function test for the system

    3. Place a copy of test result in the field maintenance
