مقدمة

This document outlines the routine testing procedures P1, which must performed on a annually bases as indicated by Y1 in the title block.

DCS QAO Card Analog Output card ( 4- 20 mA) to control valve

العمل المراد تنفيذه

Steps to Prepare for Test

  1. مراجعة المواد المرجعية الفنية ودليل التصنيع.

  2. Open DPU cabinet.

  3. باستخدام إنهاء مجلس الوزراء تحديد الموقع المطلوب QAO card.

 

Start Test

  1. Using cabinet termination list for each card identify the two O/P wires for the 2اختصار الثاني channel.

  2. Using the screw driver to remove this two wires and isolate with tape.

  3. Connect the m A tester leads to the 1شارع channel.

  4. From CCR give command 0%, 25%, 50%, 75%, 100% which equals 4m A ,8m A , 12m A , 16m A and 20m A .

  5. Compare the command from CCR using radio with the mA reading.

  6. إذا كانت القراءة جيدة أو ضمن النطاق ( + 0.01 مللي أمبير)، كرر الخطوات 1 إلى 5 للقنوات الثلاث الأخرى.

  7. If any reading for any channel in CCR not correct replace the card.

Return Card to Service

  1. إزالة م اختبار ..

  2. Reconnect the O/P to terminal strip.

  3. Close the cabinet.

  4. Place a copy of test result in the field maintenance file.
