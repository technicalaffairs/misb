مقدمة

يحتوي هذا المستند على خطوات وإجراءات اختبار مقاومة عزل محولات القدرة الكهربائية طبقاً لتعليمات الشركة المصنعة.

احتياطات السلامة والأمان

  • فصل وعزل المحول من الخدمة وتأريضه.

  • يجب إصدار تصريح وأمر شغل.

  • يجب على طاقم الاختبار المؤهل الالتزام بمعايير وفئة السلامة والصحة المهنية المناسبة.

  • تسييج منطقة العمل بحبل وشريط تحذيري محيط بالمنطقة.

  • فصل أطراف الجهد العالي والجهد المنخفض للمحول.

  • يجب تنظيف جميع عوازل الاختراق (البوشينج) جيداً لتجنب حدوث أخطاء في القراءات.

  • لا تلمس أطراف الاختبار أثناء القياس، انتبه لجهد الاختبار المسلط وقيمته 5 كيلو فولت مستمر.

الأجهزة والعدد المستخدمة

  • جهاز اختبار مقاومة العزل (الميجر) طراز BM11 D، عنوان الشركة المصنعة:
    شركة AVO International, العنوان: 4651 Single Westmorland TX 75237 - 1017 USA

الإجراءات والخطوات المطلوب تنفيذها

لكافة الاختبارات، يتم قصر عوازل الجهد العالي وعوازل الجهد المنخفض وعوازل الملف الثالث، مع التأكد من تنظيف أطراف العوازل جيداً قبل توصيل كابلات الميجر.

الاختبار رقم 1: الجهد العالي → (الجهد المنخفض + الملف الثالث + الأرضي)

  1. وصّل عوازل الجهد المنخفض المقصّرة والملف الثالث (الترشيري) المقصّر بنقطة تأريض المحول (E).

  2. وصّل الطرف الموجب (+ve) للميجر بعوازل الجهد العالي المقصّرة، والطرف السالب (-ve) بعوازل الجهد المنخفض المقصّرة.

  3. شغّل الميجر وسجّل القراءة بعد 15 ثانية (R15)، ثم سجّل قراءة أخرى بعد 60 ثانية (R60).

  4. أوقف تشغيل الميجر واحسب نسبة الاستقطاب (R60/R15).

 

الاختبار رقم 2: الجهد المنخفض → (الجهد العالي + الملف الثالث + الأرضي)

  1. وصّل عوازل الجهد العالي المقصّرة والملف الثالث (الترشيري) المقصّر بنقطة تأريض المحول (E).

  2. وصّل الطرف الموجب (+VE) للميجر بعوازل الجهد المنخفض المقصّرة، والطرف السالب (-VE) بعوازل الجهد العالي المقصّرة.

  3. شغّل الميجر وسجّل القراءة بعد 15 ثانية (R15)، ثم سجّل قراءة أخرى بعد 60 ثانية (R60).

  4. أوقف تشغيل الميجر واحسب نسبة الاستقطاب (R60/R15).

الاختبار رقم 3: الملف الثالث → (الجهد العالي + الجهد المنخفض + الأرضي)

  1. وصّل عوازل الجهد العالي المقصّرة وعوازل الجهد المنخفض المقصّرة بنقطة تأريض المحول.

  2. وصّل الطرف الموجب (+ve) للميجر بعوازل الملف الثالث (الترشيري) المقصّرة، والطرف السالب (-ve) بنقطة تأريض المحول (E).

  3. شغّل الميجر وسجّل القراءة بعد 15 ثانية (R15)، ثم سجّل قراءة أخرى بعد 60 ثانية (R60).

  4. أوقف تشغيل الميجر واحسب نسبة الاستقطاب (R60/R15).

الاختبار رقم 4: الجهد العالي → الجهد المنخفض (بدون أرضي)

  1. افصل أي تأريض مؤقت.

  2. وصّل الطرف الموجب (+ve) للميجر بعوازل الجهد العالي المقصّرة.

  3. وصّل الطرف السالب (-ve) للميجر بعوازل الجهد المنخفض المقصّرة.

  4. شغّل الميجر وسجّل القراءة بعد 15 ثانية (R15)، ثم سجّل قراءة أخرى بعد 60 ثانية (R60).

  5. أوقف تشغيل الميجر واحسب نسبة الاستقطاب (R60/R15).

الاختبار رقم 5: (الجهد العالي + الجهد المنخفض + الملف الثالث) → الأرضي

  1. قم بقصر وتوصيل عوازل الجهد العالي مع عوازل الجهد المنخفض مع عوازل الملف الثالث (الترشيري) معاً.

  2. وصّل الطرف الموجب (+ve) للميجر بعوازل الجهد العالي المقصّرة، والطرف السالب (-ve) بنقطة تأريض المحول.

  3. شغّل الميجر وسجّل القراءة بعد 15 ثانية (R15)، ثم قراءة أخرى بعد 60 ثانية (R60).

  4. أوقف تشغيل الميجر واحسب نسبة الاستقطاب (R60/R15).
